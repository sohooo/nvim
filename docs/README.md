# Neovim Config Documentation

This folder documents the current baseline for this Neovim 0.10-compatible
configuration.

- [Plugins](plugins.md): plugin inventory, config locations, and short purpose.
- [Keymaps](keymaps.md): custom keybinds added on top of Neovim defaults.

The main plugin specification lives in [`../init.lua`](../init.lua). Most
runtime configuration is split into modules under [`../lua/sohooo/`](../lua/sohooo/).
